Ce que je construis

  • Plateforme

    TestOps, piloter les tests

    Une interface web pour piloter des tests Robot Framework : choisir la cible, lancer une suite, suivre les logs en direct, ouvrir le rapport. Aucune URL dans les tests, aucun mot de passe versionné, un run qui part d'un contexte explicite. La démonstration rejoue une exécution réelle.
    Lire le code

  • Paquet Python

    crosslocator, un sélecteur par plateforme

    Le même bouton se trouve de quatre façons selon le système. Déclarer le sélecteur une fois par plateforme, et résoudre le bon à l'exécution. Sans dépendance, typé, sous licence MIT.
    pip install crosslocator
